# AWS Bahrain Struck: Blinding US Cloud

Precision missile and drone strikes have targeted the Amazon Web Services (AWS) data center and its backup servers in Bahrain. The strikes, part of the 24th wave of the IRGC's "Nasr-2" campaign, have disrupted the cloud computing infrastructure used by the U.S. military command in the Gulf. By targeting both primary nodes and backup systems, the campaign has created operational delays that disrupt combat operations.
